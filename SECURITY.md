# Security

Report a suspected vulnerability in any valinta-hire repository, or in a service one of them runs, privately by email
to utkarsh@umavanlabs.com (security@getvalinta.com once that address exists); never in a channel, an issue or a pull
request. You get an answer within two working days. In scope: the organisation's repositories and the services they
deploy; the vendors' own platforms are not. No secret, key, token, password or candidate data is ever committed to
any repository, in code, fixtures, tests, logs or commit messages. If one is, tell the owner at once so it can be
rotated: deleting it from the history is not enough. A repository's own `SECURITY.md`, where it has one, names its
scope more precisely and takes precedence over this one.
